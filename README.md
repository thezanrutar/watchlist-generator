# Random movie generator

~ from a watchlist ~

I keep my watchlist on IMDb. But when I go to pick a movie,
they're always in the same order, and there's no way to simply pick a movie without bias.

A simple GUI application lets you select a watchlist and pick a random movie to watch.

## Source

This is a Python 3.13 application and requires NumPy, Pandas, and PySide6 to run from source.

## Releases

Releases are currently for Windows and macOS.
